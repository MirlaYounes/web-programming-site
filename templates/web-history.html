The Evolution of the World Wide Web

Key developments in the creation, open release, and standardization of the WWW from 1989 to 1995.

Timeline of Web Milestones

March 1989: "Information Management: A Proposal"

Tim Berners-Lee authored a proposal at CERN describing an internet-based hypertext system designed to link and share information across incompatible computer networks.

Source: CERN

December 1990: First Web Server and Browser Go Live

Berners-Lee developed HTML, HTTP, and URLs, building the world's first web browser and web server (info.cern.ch) running on a NeXT computer at CERN.

Source: CERN

April 30, 1993: CERN Releases Web Software into the Public Domain

CERN placed the World Wide Web software into the public domain on a royalty-free basis, enabling open implementation, modification, and rapid worldwide adoption.

Source: CERN

1993: Release of the NCSA Mosaic Browser

Marc Andreessen and Eric Bina created Mosaic at NCSA. It introduced inline images alongside text in a single window, bringing the Web to a general graphical user audience.

Source: University of Illinois

October 1994: Founding of the World Wide Web Consortium (W3C)

Tim Berners-Lee established the W3C at MIT to create open web standards (such as HTML and HTTP) and prevent fragmentation across commercial software vendors.

Source: CERN Timeline
