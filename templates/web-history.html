The Evolution of the World Wide Web

Key developments in the creation, open release, and standardization of the WWW from 1989 to present.

Introduction

Many confuse the Internet for the web, but they are distinct systems. The Internet is the infrastructure that connects computers, while the web is a service that runs on top of the Internet, allowing users to access and share information through hypertext links. The web was created by Tim Berners-Lee in 1989 and has since evolved into a global platform for communication, commerce, and information sharing.This page follows the evolution of the web until now.

Timeline of Web Milestones

March 1989: "Information Management: A Proposal"

Tim Berners-Lee authored a proposal at CERN describing an internet-based hypertext system designed to link and share information across incompatible computer networks.

Source: CERN

December 1990: First Web Server and Browser Go Live

Berners-Lee developed HTML, HTTP, and URLs, building the world's first web browser and web server (info.cern.ch) running on a NeXT computer at CERN.

Source: CERN

April 30, 1993: CERN Releases Web Software into the Public Domain

CERN placed the World Wide Web software into the public domain on a royalty-free basis, enabling open implementation, modification, and rapid worldwide adoption.

Source: CERN

1993: Release of the NCSA Mosaic Browser

Marc Andreessen and Eric Bina created Mosaic at NCSA. It introduced inline images alongside text in a single window, bringing the Web to a general graphical user audience.

Source: University of Illinois

October 1994: Founding of the World Wide Web Consortium (W3C)

Tim Berners-Lee established the W3C at MIT to create open web standards (such as HTML and HTTP) and prevent fragmentation across commercial software vendors.

Source: CERN Timeline

1995: JavaScript Is Created

In 1995, Brendan Eich created JavaScript at Netscape so that instead of only showing static text and images, websites could begin responding to user actions and changing content directly inside the browser.

Source: MDN Web Docs

1996: CSS Becomes a Web Standard

In December 1996, the W3C published CSS Level 1 as a recommendation. CSS allowed web developers to control the appearance of pages, including fonts, colors, margins and spacing, separately from the HTML structure.

Source: W3C

2000s: The Rise of Web 2.0

During the 2000s, websites became more interactive and focused more on user participation. People could create and share their own content through blogs, social networks, wikis and other online platforms instead of only reading information published by website owners.

Source: O'Reilly Media

2000s: Growth of the Mobile Web

As smartphones became more common, people increasingly accessed websites from mobile devices instead of only desktop computers. This pushed web developers to create pages that could work properly on smaller screens and different types of devices.

2010: Responsive Web Design

Responsive web design became an important approach for building websites that could adapt to different screen sizes. Developers used flexible layouts, images and CSS media queries so that the same website could work on desktop computers, tablets and smartphones.

Source: A List Apart

2014: HTML5 Becomes a W3C Recommendation

On October 28, 2014, the W3C officially published HTML5 as a recommendation. HTML5 introduced new elements and features for modern websites and web applications, including better support for multimedia such as audio and video.

Source: W3C

2010s: HTTPS Becomes Widely Used

During the 2010s, more websites began using HTTPS instead of ordinary HTTP. HTTPS encrypts the connection between the user's browser and the web server, making information such as passwords and personal data safer while being transmitted.

Source: Let's Encrypt

2020s: The Modern Web

Today, the Web is used on computers, smartphones, tablets and many other connected devices. Modern websites combine HTML for structure, CSS for design and JavaScript for interactivity, while HTTPS helps provide secure communication.
