The World Wide Web (1989–1995)

The information system built on top of the Internet

Introduction

The Internet is the global network infrastructure. The World Wide Web is a separate layer that sits on top of it as an information system. In the 1980s, the Internet remained a tool used mainly by computer scientists, university researchers, and military users — not easy for regular people to use or understand. The World Wide Web changed that by turning the Internet into something much more accessible. It added features like uniform web addresses (URLs), a way to transfer data (HTTP), and a simple way to format documents (HTML). With these tools, anyone could share information easily.

This page tracks how the World Wide Web came to life between 1989 and 1995, building on the pre-existing Internet infrastructure, leading to its public release and commercialization.

Milestones of the World Wide Web

A. March 1989. "Information Management: A Proposal"

While working at CERN, Tim Berners‑Lee wrote a proposal titled "Information Management: A Proposal," which described an internet‑based hypertext system that could link and access information across CERN's incompatible computer systems. This was the documented idea of the Web as a separate system built on top of the existing internet, not the internet itself [6] [7].

B. November 1990. Formal project proposal

Berners‑Lee, with CERN colleague Robert Cailliau, submitted a formal management proposal titled "WorldWideWeb: Proposal for a HyperText Project," describing a "web" of hypertext documents navigable via "browsers." This mattered because it moved the idea from a note to an approved CERN project with clear terms and limits [7] [8].

C. December 1990. First web server, browser and webpage go live

By Christmas 1990, Berners‑Lee had built the Web's three core parts — HTML, HTTP, and the URL — and created the first web server and browser/editor, named "WorldWideWeb," which ran on his NeXT computer at CERN and was reachable at info.cern.ch. This was the moment the Web turned into a working system, not just a proposal, and the core technologies are still in use today [7] [8].

D. March 1991. The Line Mode Browser

Nicola Pellow, a CERN student, wrote the "Line Mode Browser," a text‑only browser that could run on many more computer systems than Berners‑Lee's original NeXT‑only software. This made the Web usable on computers other than the one it was invented on, which was essential for the Web to spread to other institutions [8].

E. August 1991. The Web is announced

Berners‑Lee posted details about the WorldWideWeb project to the Usenet newsgroups alt.hypertext, comp.sys.next, comp.text.sgml, and comp.mail.multi-media, giving the software and documentation to anyone on the internet. This was the Web's public release outside CERN, opening it to the wider research and hypertext community [8].

F. April 30 1993. CERN releases the Web into the public domain

CERN's directorate put the World Wide Web software into the public domain, royalty-free, letting anyone use, run, and change it without paying fees. This meant anyone could use the Web without legal barriers, which is widely seen as the biggest reason the Web grew so fast worldwide [6] [7].

G. 1993. Release of the Mosaic browser

Marc Andreessen and Eric Bina, working at the National Center for Supercomputing Applications (NCSA) at the University of Illinois Urbana‑Champaign, released Mosaic, the browser that showed inline images next to text in one window with an easy graphical interface. Mosaic made the Web look good and easy to use for people who were not tech experts, turning it from a research tool into something many people liked [10] [11].

H. October 1994. Founding of the World Wide Web Consortium (W3C)

Berners‑Lee left CERN and founded the World Wide Web Consortium at MIT's Laboratory for Computer Science, with help from CERN, the European Commission, and DARPA. This created a vendor‑independent group to set standards for Web technologies such as HTML and HTTP, preventing fragmentation as commerce grew stronger [8] [9].

I. 1994. Mosaic's Creators Found Netscape

Andreessen left NCSA and, with Silicon Graphics founder Jim Clark, started Mosaic Communications Corporation, later renamed Netscape Communications, and released the Netscape Navigator browser. This was the first major commercial browser company, starting the competitive "browser wars" that pushed rapid changes in Web standards and features [11].

J. August 9, 1995. Netscape's IPO

Netscape Communications' initial public offering is seen as the start of the commercial "dot‑com" era, as public and investor interest in the Web grew. The Web changed from a research tool into a mainstream commercial and cultural phenomenon [11].

Synthesis

Using the pre-existing Internet backbone, the World Wide Web appeared from 1989 to 1995 and changed the way people find information and communicate with one another. The World Wide Web combined hypertext with application protocols such as HTTP, HTML, and URLs, and gave away its source code for free. This move by CERN and early Web pioneers made it easier for people around the world to join in. Later, graphical browsers such as Mosaic and Netscape brought the Web to a mass audience, and groups like the W3C set standards to keep it from fragmenting. These steps completed the World Wide Web's transformation from a research tool inside labs into a part of everyday business and society.
