The World Wide Web (1989–Present)

The evolution of the information system built on top of the Internet

Introduction

The Internet is the global network infrastructure that allows computers and devices to communicate. The World Wide Web is a separate information system that operates on top of the Internet. Before the Web, the Internet was mainly used by researchers, universities, government organizations, and technical communities.

The invention of the World Wide Web made Internet-based information much easier to access. Technologies such as URLs, HTTP, and HTML allowed users to locate, transfer, and display connected documents through web browsers. Over time, additional technologies such as JavaScript and CSS transformed websites from simple documents into interactive and visually designed applications.

This page follows the development of the World Wide Web from Tim Berners-Lee's original proposal in 1989 to modern web standards, mobile browsing, secure HTTPS connections, and the interactive Web used today.

Milestones of the World Wide Web

A. March 1989. "Information Management: A Proposal"

While working at CERN, Tim Berners-Lee wrote a proposal titled "Information Management: A Proposal." It described an Internet-based hypertext system that could connect information stored on different computer systems at CERN. This became the foundation for what would later become the World Wide Web [1] [2].

B. November 1990. Formal WorldWideWeb Project Proposal

Tim Berners-Lee and CERN colleague Robert Cailliau submitted a more detailed proposal for a hypertext system called WorldWideWeb. The proposal described a system of linked documents that users could navigate using browser software. This helped transform the original concept into a practical development project [2] [3].

C. December 1990. First Web Server, Browser, and Website

By the end of 1990, Berners-Lee had developed the main technologies required for the Web, including HTML, HTTP, and URLs. He also created the first web browser and editor, called WorldWideWeb, and the first web server at CERN. The first website was hosted at info.cern.ch [2] [3].

D. 1991. The Line Mode Browser

Nicola Pellow developed the Line Mode Browser at CERN. Unlike Berners-Lee's original browser, which worked on a NeXT computer, the Line Mode Browser could run on a wider variety of systems. This helped make the Web accessible to more users and institutions [3].

E. August 1991. The Web Becomes Publicly Available

Berners-Lee announced the WorldWideWeb project on Internet discussion groups and made information about the software available outside CERN. This allowed researchers and developers around the world to experiment with the Web and create their own web servers and pages [3].

F. April 30, 1993. CERN Releases Web Technology Freely

CERN released the World Wide Web software on a royalty-free basis. This meant that individuals, universities, and companies could use and develop Web technology without paying licensing fees. The decision helped the Web spread rapidly around the world [1] [2].

G. 1993. Release of the Mosaic Browser

Marc Andreessen and Eric Bina developed the Mosaic browser at the National Center for Supercomputing Applications. Mosaic displayed text and images together in the same browser window and provided a graphical interface that was easier for non-technical users. It helped introduce the Web to a much wider audience [4] [5].

H. 1994. Founding of the World Wide Web Consortium

Tim Berners-Lee founded the World Wide Web Consortium, or W3C, at MIT. The organization was created to develop open standards for technologies such as HTML and HTTP and to help ensure that the Web remained compatible across different browsers, devices, and software systems [6].

I. 1994. Netscape and the Beginning of the Browser Wars

Marc Andreessen and Jim Clark founded Mosaic Communications Corporation, later renamed Netscape Communications. Netscape Navigator became one of the most popular early commercial web browsers. Competition between browser companies accelerated the introduction of new web features during the 1990s [5].

J. 1995. JavaScript Introduces Interactive Web Pages

Brendan Eich developed JavaScript while working at Netscape in 1995. JavaScript allowed programs to run directly inside web browsers, making websites more interactive. Instead of displaying only static documents, pages could respond to user actions, change content, validate forms, and later support complex web applications [7].

K. 1996. CSS Adds Web Page Styling

The World Wide Web Consortium published the first Cascading Style Sheets specification, known as CSS1, in 1996. CSS allowed developers to separate the visual appearance of a page from its HTML structure. This made it easier to control colors, fonts, spacing, layouts, and other design features across multiple pages [8].

L. Late 1990s. Growth of Search Engines and Commercial Websites

As the number of websites increased rapidly, search engines became increasingly important for finding information online. Businesses also began using websites for advertising, communication, online shopping, and digital services. The Web was becoming a major commercial and public platform rather than only a collection of research documents.

M. Early 2000s. The Rise of Web 2.0

During the early and mid-2000s, the term "Web 2.0" became widely used to describe a more interactive and participatory form of the Web. Instead of mainly reading static pages, users increasingly created and shared their own content through blogs, social networks, wikis, video platforms, and other online services. Websites increasingly behaved like interactive applications rather than simple documents.

N. Mid-to-Late 2000s. The Mobile Web Expands

The growth of smartphones changed how people accessed the Web. Mobile browsers allowed websites to be viewed away from desktop computers, while developers increasingly designed pages that could adapt to smaller screens and touch-based devices. Mobile access eventually became one of the main ways people used the Web.

O. 2010. Responsive Web Design

The idea of responsive web design became influential as websites needed to work across desktop computers, tablets, and smartphones. Using flexible layouts, images, and CSS media queries, developers could create pages that automatically adapted to different screen sizes instead of maintaining separate versions of the same website.

P. October 2014. HTML5 Becomes a W3C Recommendation

In October 2014, the W3C published HTML5 as an official Web standard. HTML5 added new semantic elements, improved support for audio and video, and introduced features for building more advanced web applications without depending as heavily on external browser plugins [9].

Q. 2010s. HTTPS Becomes the Standard for Secure Web Communication

During the 2010s, the Web increasingly moved from ordinary HTTP connections to HTTPS. HTTPS encrypts communication between a user's browser and a web server, helping protect passwords, personal information, and other data from interception. Browser vendors, web companies, and certificate initiatives encouraged websites to adopt HTTPS more widely.

R. 2015. Free HTTPS Certificates through Let's Encrypt

Let's Encrypt began providing free automated digital certificates for websites. By reducing the cost and complexity of enabling HTTPS, the service helped many more website owners encrypt their web traffic and contributed to HTTPS becoming common across the modern Web [10].

S. Late 2010s–2020s. Web Applications Become More Powerful

Modern browsers increasingly supported complex applications that previously required separately installed desktop software. Web-based email, office software, video conferencing, streaming services, cloud platforms, and collaborative tools became common. Advances in JavaScript, browser APIs, HTML, and CSS helped make these applications possible.

T. 2020s. The Modern Web

Today, the World Wide Web operates across computers, smartphones, tablets, televisions, and many other connected devices. Modern websites combine HTML for structure, CSS for presentation, JavaScript for behavior, secure HTTPS connections, and online services hosted across global Internet infrastructure. The Web continues to evolve through open standards developed by international organizations and browser developers.

Synthesis

The World Wide Web began as a system for sharing linked research documents, but it developed into one of the most widely used information platforms in the world. Tim Berners-Lee's original technologies, including HTML, HTTP, and URLs, provided the basic structure of the Web, while the free release of Web technology by CERN allowed it to expand without major licensing restrictions.

During the second half of the 1990s, technologies such as JavaScript and CSS made websites more interactive and visually flexible. In the 2000s, Web 2.0 introduced a stronger focus on user-generated content and interactive services, while smartphones and responsive design expanded the Web onto mobile devices.

HTML5, HTTPS, modern browser technologies, and increasingly powerful web applications continued this development during the 2010s and 2020s. The modern Web is now used for communication, education, entertainment, business, social interaction, cloud applications, and many other activities, while still operating on top of the Internet infrastructure that existed before it.
